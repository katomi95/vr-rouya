# VR牢屋

**体験できるURL：https://katomi95.github.io/vr-rouya/**（Meta Quest 3 のブラウザで開いてください。PCではプレビューモードで見られます）

**こんなVRはイヤだ。**

Meta Quest 3 のパススルーMRで、自分の部屋が刑務所の独房になるだけの作品です。
ゲームではありません。脱出も、謎解きも、スコアも、クリアもありません。
はじまると牢屋が出現し、そのあとは基本的に何も起きません。ときどき遠くで鉄の音がして、まれに看守が通りかかります。

自由になるためには、ヘッドセットを外すしかありません。

## Quest 3 での起動手順

1. このフォルダを HTTPS の静的ホスティング（GitHub Pages など）に置く。WebXR は `https://`（または `localhost`）でしか動きません。
2. Quest 3 の **ブラウザ** でそのURLを開く。
3. 設定（部屋のサイズ・鉄格子の密度・演出の強度・音量・看守の声）を選び、**「収監される」** を押す。パススルー（と空間設定の読み取り）の許可を求められたら許可する。
4. **配置 1/3 正面を決める**：部屋のまん中あたりに立ち、部屋のドアの方を向いて「この向きで決定」。
   - 空間設定（Quest の「空間設定」で部屋をスキャン済み）が読めた場合は、壁・天井・ドアの位置に自動で合わせます。
5. **配置 2/3 部屋の大きさ**：黄色い線が現実の床と壁の角に重なるよう、幅・奥行・高さ・位置・向きを調整して「次へ」。
   - コントローラーなら、左スティックで移動、右スティック左右で回転もできます。
   - 床の高さが取れない環境では「床 ▲▼」が出ます。
6. **配置 3/3 鉄扉の位置**：鉄扉を現実のドアに重ねて「収監される」。扉は壁に沿って動かせ、角を越えると隣の壁へ回り込みます。
7. 扉が閉まり、閂がかかり、看守が去っていきます。あとはお好きなだけ。

パネルはコントローラーの光線（またはハンドトラッキングの手の光線）で指し、トリガー（またはピンチ）で押します。何もない所を指してトリガーを引くと、パネルが手元に戻ってきます。

### おわるとき

- トリガー（またはピンチ）を引くと、正面に「おわる」が出ます。それを指してもう一度。何もしなければ7秒で消えます。
- Meta ボタン → 終了（Quest のシステム操作はいつでも使えます）。
- ヘッドセットを外す。

### PC でのプレビュー

タイトルの「PCプレビュー」で、仮の部屋（6畳・ベッドと机とドア）に牢屋を重ねて見られます。
ドラッグで見回し、WASD／矢印キーで歩き、クリックがトリガーの代わりです。

確認用の URL パラメータ：

| パラメータ | 内容 |
| --- | --- |
| `?skip=1` | 配置を飛ばしてすぐ収監（プレビュー・XR とも） |
| `?fakeplanes=1` | プレビューで「空間設定が読めた」場合を試す（仮の部屋の壁・天井・ドアを平面として渡す） |

ローカルで動かすときは、`.js` を `text/javascript` で返すサーバーで配信してください（例：`python -m http.server`）。

## 中身

| 演出 | 内容 |
| --- | --- |
| 鉄格子 | 部屋の4面すべて。太さ4.2cmの黒ずんだ鉄棒、横の補強材3段、床と天井のレール、四隅の角柱、交点の鋲。錆・しずく・引っかき傷は起動時に Canvas で生成 |
| 鉄扉 | 灰緑の塗装が剥げた鋼板。覗き窓（細い格子付き）、閉じた食器口、錆びた蝶番3つ、大きな閂と南京錠。開かない。内側に取っ手はない |
| 囚人番号プレート | 扉の横の鉄格子に留めた金属板。番号は毎回ランダムの4桁 |
| 監視カメラ | 扉の壁の、扉から遠い方の天井の隅。数秒おきに、あなたの頭の方へ首を振る（小さなモーター音）。録画ランプが2秒ごとに点く |
| 監視灯 | 天井の中央、かご付きの電球（「控えめ」では無し）。消灯時間になると消える |
| 換気口 | 扉の向かいの壁の天井近く。低い動作音はここから鳴る |
| 床の格子の影 | 廊下の明かりが鉄格子越しに差し込んでいる、という見立ての薄い影 |

音はすべて WebAudio で合成しています（音声ファイルなし）。HRTF の立体音響で、換気音・遠くの金属音・遠くで閉まる鉄扉・看守の足音・鍵束・閂の音を、それぞれの場所から鳴らします。

看守の声（「囚人番号、○○○○。点呼！」「静粛に！」「消灯時間だ！」「面会は許可されていない！」など）は Web Speech API の日本語音声で読み上げます。

### 演出の強度

| | 控えめ | ふつう | 本格的 |
| --- | --- | --- | --- |
| 遠くの物音の間隔 | 70〜160秒 | 40〜100秒 | 22〜60秒 |
| 看守の巡回の間隔 | 6〜9分（初回 2〜3分） | 3〜5分（初回 80〜130秒） | 100〜200秒（初回 50〜80秒） |
| 監視灯・消灯 | なし | あり | あり |
| 床の影 | ごく薄い | 薄い | やや濃い |

どの強度でも、ほとんどの時間は換気音だけの静寂です。

## 安全のために

- 鉄格子・鉄扉などの仮想物体には当たり判定がありません。すり抜けます。移動を強制することもありません。
- 現実の家具はパススルーでそのまま見えます。鉄格子は隙間だらけなので、向こうの壁や家具も見えます。
- 鉄扉は半透明（不透明度 78〜92%）で、**近づくとさらに透けます**（約0.5mで32%）。現実のドアや出入口を確認できるようにするためです。
- 人工的な移動・カメラの揺れ・急な視点移動はありません。監視灯がまれに少し暗くなることはありますが、点滅はしません。
- Quest のシステム操作（Meta ボタン）はいつでも使えます。

## 制約事項と未対応

- **Quest 3 実機では未確認です。** PCブラウザのプレビューでのみ動作を確認しています（下の確認項目を参照）。
- 現実の物による遮蔽（オクルージョン）は既定ではありません。CG は常に現実の手前に描かれるので、壁際の家具の「手前」にも鉄格子が見えます。
  - 詳細設定の「家具の後ろの鉄格子を隠す（深度センサー・実験的）」をオンにすると、WebXR の `depth-sensing` を要求し、three.js r165 の機能で遮蔽します。端末が断れば、それ抜きで始まります。オンのときは鉄格子を壁から12cm内側に置きます（壁とのちらつき防止）。実機での見え方は未確認です。
- 空間設定（`plane-detection`）は「使えたら使う」です。Quest で部屋のスキャンをしていない、許可しなかった、ブラウザが対応していない場合は手動配置になります。ドアの自動配置は、平面のラベルに `door` が含まれる場合だけです。
- 空間メッシュ（`mesh-detection`）、ヒットテスト、アンカーは使っていません。配置はセッションごとにやり直しです（保存されるのは設定とサイズだけ）。
- 部屋は長方形として扱います。L字の部屋や斜めの壁には合いません。
- 看守の声は speechSynthesis のため**立体音響になりません**（廊下からではなく、頭の中で聞こえます）。日本語の音声がない端末、Web Speech API がない端末では、看守は黙っています。Quest ブラウザの immersive セッション中に読み上げが鳴るかは未確認です。
- 監視灯の明かりは鉄格子などの CG にだけ当たり、現実の部屋は照らしません。消灯しても部屋は暗くなりません。
- 金属の映り込みは仮の明るさ（上が明るく下が暗い）で、現実の部屋の照明は反映しません。

## 実機で確認してほしいこと

1. 「収監される」でパススルーが始まり、配置パネルが正面に出るか
2. 1ページ目で、黄色い線の独房が頭の向きについて回るか
3. 空間設定がある部屋で、2ページ目の寸法が実際の部屋とおおよそ合うか（「読み取りました」と出るか）
4. 空間設定でドアを登録している場合、鉄扉が現実のドアに重なるか
5. コントローラーとハンドトラッキングの両方で、パネルのボタンが押せるか
6. 左右のスティックで独房を動かせる・回せるか
7. 床の高さが合っているか（鉄格子の下端のレールが床に接しているか）
8. 扉が閉まる音・閂の音が扉の方向から聞こえるか。閂が動いて南京錠が出るか
9. 鉄格子の質感（黒ずみ・錆）が、パススルーの上で平たいシールに見えないか
10. 鉄扉に近づくと透けて、現実のドアが見えるか
11. 監視カメラがときどき頭の方へ向き直るか
12. 換気音が換気口の方向から聞こえるか、音量スライダーが効いているか
13. 看守の巡回（ふつうで初回 80〜130秒後）：足音が廊下を近づき、扉の前で止まり、声がして、去っていくか。声が出るか
14. トリガーで「おわる」が出て、選ぶとブラウザに戻るか
15. 10分ほど置いておいても重くならないか（描画は約26回・1.5万ポリゴン程度）
16. 深度センサーをオンにしたとき、壁際の家具の後ろの鉄格子が隠れるか、ちらつかないか

## ファイル

```
index.html        タイトル画面と設定
style.css
js/main.js        起動・XR／プレビュー切替・配置・選択・メインループ
js/settings.js    設定の既定値・プリセット・保存
js/cell.js        独房（鉄格子・鉄扉・プレート・監視カメラ・監視灯・換気口・床の影）
js/builder.js     箱と円柱を1つのジオメトリにまとめる道具
js/textures.js    鉄・塗装鋼板・プレートのテクスチャを Canvas で生成
js/placement.js   配置パネルの3ページと、平面検出から部屋の形を読む処理
js/ui3d.js        XR内のパネル・「おわる」ボタン・光線
js/director.js    進行（ほとんど何も起きない）と看守のセリフ
js/audio.js       WebAudio の合成音と立体音響
js/voice.js       看守の声（speechSynthesis）
vendor/three.module.min.js   three.js r165（CDNに依存しないよう同梱）
```

外部への通信はありません（フォントも端末のものを使います）。
